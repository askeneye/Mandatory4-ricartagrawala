# Instructions for running the program

## Run nodes
There are sat up 4 ports for nodes to run, the ports depend on the node id thus when running the program you will have to choose between 1, 2, 3 or 4 as an id.

This also means that the program is limited to running 4 nodes at once as there are not enough ports to run more than 4 node.

Each node has to be run from its own terminal

## Run node(s) from terminal
From the project root:
go run ./cmd/node <id> //Where id can be 1 through 4
